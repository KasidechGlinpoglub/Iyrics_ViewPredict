# ชุดเพลงไทยสามคลาส

เกณฑ์ของรอบนี้คืออย่างน้อย 320 ศิลปิน ศิลปินละ 3–5 เพลง และอย่างน้อย 151 ช่องที่มีเพลงผ่านจริง ใช้ MV ทางการและยอดสะสมจากวันเดียวกันตามเวลาไทย คำตอบของโมเดลคือ ต่ำกว่า 100,000 วิว, ตั้งแต่ 100,000 ถึงต่ำกว่า 1 ล้านวิว และตั้งแต่ 1 ล้านวิว

## เก็บชุดใหม่จาก clone

ติดตั้งแพ็กเกจจาก requirements.txt และตั้ง `YOUTUBE_API_KEY` ใน `.env` ตาม README ไฟล์ [expanded_channels.csv](../data/expanded_channels.csv) เป็นรายชื่อผู้สมัครจากแค็ตตาล็อกเดิมและ YouTube Data API ใช้คำค้นเก้าชุด ครอบคลุมเพลงไทย ป๊อป ร็อก แร็พ อินดี้ ลูกทุ่ง หมอลำ เพื่อชีวิต และเพลงใต้ ค้นแยกตามปี 2018–2026 รวม 81 คำขอ รายชื่อระบุปีและคำค้นแรกที่พบช่อง ใช้ไฟล์นี้ซ้ำหรือเพิ่มช่องด้วย channel ID และจำนวนคลิปที่จะตรวจต่อช่อง

```sh
python -m scripts.collect_expanded_candidates data/expanded_channels.csv data/.local/expanded
python -m scripts.build_expanded_dataset preview data/songs.csv data/.local/expanded/candidates.csv
```

คำสั่งเก็บบันทึกรายการอัปโหลดต่อช่องในไดเรกทอรีย่อย uploads และใช้ไฟล์เดิมเมื่อรันซ้ำ คำสั่ง `--offline` ใช้สำเนาที่มีเพื่อตรวจด้วยตัวกรองใหม่ ในการรันรอบใหม่หรือเพิ่มขนาดการตรวจต่อช่อง ให้เลือกไดเรกทอรีเก็บข้อมูลรอบใหม่ รายงาน channels.csv แสดงสถานะกับจำนวนเพลงที่ผ่านต่อช่อง และ screening.csv บันทึกสาเหตุที่เก็บหรือคัดออกตาม ID

`data/songs.csv` ในตัวอย่างคือชุดอ้างอิง 711 เพลงที่ทีมส่งแยกจาก Git สามารถเพิ่มไฟล์ผู้สมัครหลัง arguments เดิมได้หลายไฟล์ คอลัมน์ใช้รูปแบบเดียวกับ candidates.csv ช่องที่มีเพลงไม่ครบให้ตรวจเครดิต แหล่งเนื้อร้อง และเวอร์ชันก่อนรวบรวมข้อมูลเพิ่ม คำสั่ง preview แสดงจำนวนศิลปินและช่องที่ยังขาด

```sh
python -m scripts.build_expanded_dataset lock data/songs.csv data/.local/expanded/candidates.csv --output data/.local/new-snapshot
python -m scripts.build_expanded_dataset snapshot data/.local/new-snapshot
python -m scripts.validate_expanded_dataset data/.local/new-snapshot/songs.csv
```

ล็อก ID กลุ่มศิลปิน และ hash เนื้อร้องของรายการที่เลือกก่อนเรียกยอด บันทึกแหล่งเนื้อร้องกับแถวที่เลือก ชุดทดสอบใช้กลุ่มเพลงที่เพิ่มใหม่ ชุดฝึกอ้างอิงเลือกจากแถว original และโมเดลขยายใช้ฝั่งฝึกทั้งหมด ทั้งคู่ใช้เนื้อร้องอย่างเดียวและหาพารามิเตอร์ภายในฝั่งฝึกตามกลุ่มศิลปิน

## เทรนซ้ำจากไฟล์ที่ทีมส่งให้

ใช้ songs.csv จากชุด snapshot ที่ทีมส่งให้ จับคู่กับไฟล์แบ่งชุดที่อยู่ใน Git ด้วย video_id

```sh
python -m scripts.evaluate_expanded_dataset data/.local/expanded-final/songs.csv data/songs_expanded_split.csv data/.local/new-evaluation
```

ผลออกเป็น report.json และโมเดลฝั่งฝึกชื่อ lyrics_nb.joblib ในโฟลเดอร์ที่ระบุ โมเดลสำหรับงานในเครื่องมีเนื้อร้องฝึกเพื่อใช้กับปุ่มตัวอย่างและรายการเพลงคล้าย

## ผลรอบวันที่ 19 พฤศจิกายน 2026

ตรวจรายการอัปโหลดสำเร็จ 731 จาก 751 ช่อง คำขอของอีก 20 ช่องได้ข้อผิดพลาดจาก API ตัวกรองได้ผู้สมัคร 1,860 เพลงจาก 328 ช่อง นำมาคัดร่วมกับสำเนาผู้สมัครที่ผ่านการคัดเบื้องต้นจาก v3 และไฟล์อ้างอิง 711 เพลงที่เก็บในเครื่อง ผลสุดท้ายผ่านการตรวจเกณฑ์ทั้งสามข้อ

- **1,306 MV / 367 ศิลปิน / 151 ช่อง** มีศิลปินที่ได้ 3, 4 และ 5 เพลง จำนวน 248, 33 และ 86 ราย ตามลำดับ
- ฝึก 1,042 เพลง ประกอบด้วย 711 เพลงเดิมและอีก 331 เพลง ทดสอบ 264 เพลงจาก 88 กลุ่มที่แยกจากฝั่งฝึก
- อ่านยอดทุกเพลงในช่วง 05:07:02–05:07:07 น. เวลาไทย วันที่ 19 พฤศจิกายน 2026
- ตรวจเนื้อร้องเพิ่มด้วยกติกากรองเครดิตและโปรโมต และตรวจรายชื่อศิลปินและเวอร์ชันที่น่าสงสัยบางรายการ ความถูกต้องอาศัยข้อมูลเครดิตและชื่อคลิป การตรวจรอบนี้ยังไม่ได้ฟังยืนยันทุก MV หรือยืนยันนามแฝงทั้งหมด

การเพิ่มเพลงฝึก 331 เพลงทำให้รุ่นขยายทายคลาสหลักล้านถูกเพิ่ม 3 เพลงและทายคลาสหลักแสนถูกลดลง 3 เพลง จำนวนที่ถูกทั้งหมดจึงเท่าเดิม ทั้งสองรุ่นทายถูกน้อยกว่า baseline 16 เพลง
