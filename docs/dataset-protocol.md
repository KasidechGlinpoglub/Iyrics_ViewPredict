# เกณฑ์คัดเพลงและนิยามยอดวิว

ชุดข้อมูลนี้ใช้ทดสอบว่าเนื้อร้องเพียงอย่างเดียวช่วยทำนายช่วงยอดวิวสะสม ณ วันเก็บข้อมูลของ MV เพลงไทยได้แค่ไหน

## เพลงและคลิปที่รับ

- หนึ่งแถวต่อหนึ่งเพลง ใช้ MV ทางการแบบเต็มเพลงที่เผยแพร่โดยศิลปิน ค่าย หรือผู้เผยแพร่ที่ระบุในเครดิต เพลงต้องร้องภาษาไทยเป็นหลักและมีเนื้อร้องที่ตรวจได้ว่าตรงกับเพลงและเวอร์ชันใน MV
- ใช้เครดิตระบุชื่อเพลงและศิลปิน เก็บชื่อช่องแยกจากชื่อศิลปิน ถ้ายืนยันเจ้าของช่อง ชื่อศิลปิน หรือเวอร์ชันไม่ได้ ให้พักแถวไว้ตรวจ
- รับ MV ที่เข้าเกณฑ์ทุกอายุ ตัด cover, remix, live session, lyric video, audio-only, Shorts, teaser, medley และคลิปอัปโหลดซ้ำ ถ้าพบ MV ทางการของเพลงและเวอร์ชันเดียวกันหลายคลิป ให้ใช้คลิปที่เผยแพร่ก่อน ถ้าเวลาเผยแพร่ตรงกัน ให้ใช้ `video_id` ตัวแรกเมื่อเรียงตามตัวอักษร

## ช่องสำหรับรอบทดลอง

กำหนดรายชื่อช่องชุดแรกไว้ก่อนเก็บยอดวิว โดยใช้รายการอัปโหลดของช่องเป็นจุดเริ่มต้นและเลือกตามเกณฑ์ MV ข้างต้น ช่องศิลปินช่วยให้มีตัวเลือกของงานที่ปล่อยเอง ให้ตรวจเครดิตของแต่ละ MV เพื่อยืนยันว่าเป็นงานอิสระหรือมีค่ายร่วมเผยแพร่

| ประเภทช่อง | รายชื่อ |
|---|---|
| ช่องค่าย | [GeneLab](https://www.youtube.com/@genelab), [SMALLROOM](https://www.youtube.com/channel/UC1T-ZwcYVQB6EpqOQD10tmw), [YUPP!](https://www.youtube.com/@yuppofficial) |
| ช่องศิลปิน | [TangBadVoice](https://www.youtube.com/@TangBadVoice), [Safeplanet](https://www.youtube.com/@safeplanetband), [TIMETHAI](https://www.youtube.com/@timethaiofficial) |

ถ้ามี MV เข้าเกณฑ์น้อย ให้เพิ่มช่องโดยบันทึกชื่อและเหตุผลก่อนเปิดดูยอดวิวของช่องที่เพิ่ม เก็บรายการเพลงที่รอตรวจหรือหาเนื้อร้องไม่พบไว้ด้วย เพื่อให้ตรวจได้ว่าเพลงหลุดจากชุดข้อมูลในขั้นตอนไหน

## วันเก็บยอดและช่วงยอดวิว

1. กำหนดวันเก็บตามเวลาไทย (`Asia/Bangkok`) แล้วเก็บยอดของทุกแถวภายในวันนั้น
2. ใช้ยอดสะสม `statistics.viewCount` ของ `video_id` ที่เลือก บันทึก `published_at` และเวลาที่ดึงยอดจริงใน `views_collected_at` พร้อม `views` ถ้ายอดขาดหาย ให้ลองดึงใหม่ภายในวันเก็บหรือพักแถวไว้ [เอกสาร YouTube Data API](https://developers.google.com/youtube/data/reference/rest/v3/videos#statistics.viewCount)
3. ใช้ยอดที่บันทึกในรอบเดียวกันเป็นคำตอบสำหรับเทรนและประเมินผล รายงานวันที่เก็บและช่วงอายุคลิปควบคู่กับผล เพราะ MV ที่เผยแพร่มานานมีเวลาสะสมวิวมากกว่า ใช้ `published_at` และ `views_collected_at` คำนวณอายุคลิปเพื่อเปรียบเทียบผลของเพลงใหม่กับเพลงเก่า

| ระดับ | ยอดวิวสะสม |
|---|---:|
| ไม่ดัง | ต่ำกว่า 100,000 |
| เฉย ๆ | 100,000 ถึงต่ำกว่า 1,000,000 |
| ดัง | 1,000,000 ถึงต่ำกว่า 20,000,000 |
| ดังมาก | 20,000,000 ถึงต่ำกว่า 100,000,000 |
| Fucking Viral | ตั้งแต่ 100,000,000 |

ชุดแบ่งสำหรับประเมินโมเดลใช้สี่คลาส โดยรวม Fucking Viral ไว้ในคลาสดังมาก รายการแบ่งชุดและจำนวนเพลงอยู่ใน [รายงานชุดข้อมูล](training-dataset.md)

เก็บ `data/demo_songs.csv` ไว้ทดสอบการรันโปรแกรม ใช้ชุดเพลงจริงตามเกณฑ์ข้างต้นสำหรับการวัดผลของโปรเจกต์
